Responsive CSS Cheat Sheet

Essential definitions and syntax for modern responsive design

CSS Filters

Graphical effect primitives applied to raster and vector nodes without mutating raw asset streams.

filter: blur(5px) grayscale(80%);

Media Queries

Conditional CSS logic blocks evaluated by viewport capabilities, dimensions, and hardware orientations.

@media (max-width: 768px) { ... }

Responsive Design

An architectural philosophy unifying fluid proportions, flexible media containers, and modular layouts.

width: 100%; max-width: 1200px;

Typography

Calculated proportional scaling based on dynamic viewport percentages and bound constraints.

font-size: clamp(1rem, 2.5vw, 2rem);
