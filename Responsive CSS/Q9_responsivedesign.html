Fluid Layouts

Uses relative units such as percentages, viewport units (vw, vh), and flex fractions instead of hardcoded pixel coordinates.

.container {
  width: 100%;
  max-width: 1200px;
}

Flexible Media

Prevents images, videos, and embedded canvases from overflowing their containing layout boundaries across device screens.

img, video {
  max-width: 100%;
  height: auto;
}

Breakpoints

Uses CSS media query conditions to reconfigure grid columns, hide secondary chrome, and reorder content for target devices.

@media (min-width: 768px) {
  .grid {
    grid-template-columns: 1fr 1fr;
  }
}
