# Assignment 1 – Introduction to Web Development

## Q1. Difference between Frontend, Backend and Full-Stack Development

### Frontend Development
Frontend development is the part of a website that users can see and interact with. It includes buttons, menus, images, forms and page layout.

**Technologies:** HTML, CSS, JavaScript

**Example:** The product page and **Add to Cart** button on Amazon.

### Backend Development
Backend development is the server-side part of a website. It processes requests, manages business logic and communicates with the database.

**Technologies:** Java, Python, Node.js, MySQL

**Example:** Checking login credentials and fetching user data.

### Full-Stack Development
A Full-Stack Developer works on both frontend and backend and can build a complete web application.

**Example:** Building an online food delivery website.

| Frontend | Backend | Full-Stack |
|---|---|---|
| User Interface | Server & Database | Both |
| Visible | Not Visible | Both |
| HTML, CSS, JS | Java, Python, MySQL | Uses both |

## Q2. Client-Server Model

```text
Client (Browser)
      |
 HTTP Request
      |
      v
    Server
      |
 HTTP Response
      |
      v
Client Displays Web Page
```

The browser sends a request to the server. The server processes it and sends the requested webpage back.

## Q3. How a Browser Requests a Web Page

1. User enters a URL.
2. Browser sends an HTTP/HTTPS request.
3. Server processes the request.
4. Database is accessed if required.
5. Server sends a response.
6. Browser displays the webpage.

## Q5. What is a Web Server?

A web server stores website files, receives requests from browsers and sends webpages back to users.

**Examples:** Apache, Nginx, Microsoft IIS.

## Q6. Roles

### Backend Developer
Develops server-side logic and connects the application with databases.

### Database Administrator (DBA)
Manages, secures and maintains databases.
