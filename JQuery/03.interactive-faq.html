Frequently Asked Questions

1. What is jQuery?

jQuery is a JavaScript library that simplifies DOM manipulation and events.

2. Is jQuery free?

Yes, jQuery is free and open-source.

3. Can I use jQuery with HTML?

Yes, include the jQuery library in your HTML page.

4. What does click() do?

It attaches a handler that runs when an element is clicked.

5. What is an event?

An event is an action such as click, hover, focus, or blur.
